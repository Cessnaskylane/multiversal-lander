## Product logic (kept from live)

1. **Door** — enter / open door into the agent frame  
2. **Your agent / Model** — portrait + Select model chips + Continue; gate *please select a model*  
3. **Select verses** — social/tool chips + Back/Continue; gate *please select verses*  
4. **Select a layer** — Celebrity / Skill / Upload + Back  
5. **Skill layers** — grid + Back/Continue  
6. **Celebrity layers** — ribbon list + Back/Continue  
7. **Upload layer** — Brain file + Back/Continue  
8. **Verse** — face frame + verse rail + Back  
9. **Job outcome** — e.g. Post a video + Copy + Back  

Header: spaced **MULTIVERSAL · ai** (light glass), quiet `hello@` / My account.  
Promise (soft): *A named voice you put on Grok.*  
YouTube **@multiversalbots** is a first-class verse chip (not a stage strip).

Chips/buttons: frosted glass pills / hairline. Selected = soft ice highlight + thin dark hairline.
